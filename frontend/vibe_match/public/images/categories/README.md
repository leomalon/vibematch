## Formato recomendado

- **Tamaño:** 520×320 px (relación 13:8, cubre el área de 260×160 de la tarjeta con `object-fit: cover`)
- **Formato:** PNG (con transparencia opcional) o SVG
- **Estilo:** Imagen de fondo borrosa o patrón que combine con el gradiente dark de la página

Si falta una imagen, la tarjeta muestra `default.png`. Si falta `default.png`, se ve un fondo gris oscuro.
